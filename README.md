Code and data for the article:
"Developmental Organization of Neural Dynamics Supporting Social Processing: Evidence from Naturalistic fMRI in Children and Adults" _Developmental Cognitive Neuroscience_ (2026)


The repository focuses on three main components:
1. **CAP analysis:** identify recurring whole-brain activity patterns and characterize individual CAP state sequences and dynamics.
2. **Reverse correlation–based event detection:** locate theory-of-mind (ToM) and pain-related movie segments based on adult network responses.
3. **Partial least squares structural equation modeling (PLS-SEM):** examine associations among age, event-related CAP engagement, ToM performance, and empathy in children.
